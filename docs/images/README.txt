Crucible — Logo export
======================

Final mark: a dataset "contact sheet" that curates down to a C.

Files
-----

crucible-icon.svg          App icon — emerald rounded square, dark C (scalable)
icons/crucible-icon-*.png  App icon raster: 256/32/16 (the sizes the app ships;
                           see frontend/public/). The original export also had
                           1024/512/128/64/48 and a crucible-mark raster set —
                           dropped as unused; regenerate from the SVGs if needed.
Crucible Logo Animated.html Standalone looping animation (drop into a splash/loader)

vanish passes. The static logo is the resolved (vanished) C.
